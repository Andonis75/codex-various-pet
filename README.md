# Codex Various Pet

[English](README.en.md)

**给 Codex 这个仓库链接、一张角色图和一句需求，让它操作你已登录的 ChatGPT 网页，把角色做成 Codex 桌面宠物。**

你不需要先手动安装技能或逐条运行处理命令。Codex 读取仓库说明后准备环境，再自己上传参考、逐状态生成和下载原图、检查缺陷并重试，最后拼图、审查真实动作并安装。默认只需要你原来的 ChatGPT 页面和最终 Codex 成品，无需再操作额外预览网站。

## 直接交给 Codex

在能访问本机文件、终端和浏览器的 Codex 任务中附上参考图，发送：

> 请读取 https://github.com/Andonis75/codex-various-pet 的 README 和 AGENTS.md，按仓库说明准备环境，再读取其中的 various-pet 技能。把我附上的角色图做成 Codex 桌面宠物，名字叫“猫猫”。使用我已登录的内置浏览器 ChatGPT 网页，保持角色和画风，补齐九种动作。你自己生成、下载原图、检查缺陷和重试，在后台审查真实动作，合格后安装到本机 Codex。不要每做一步就等我说继续，也不用让我操作额外预览页面，最后告诉我结果。只有登录、人机验证或确实缺工具时再停下来说明。

名字、画风和动作偏好可以直接改在这段请求中。如果已有初版或动作条，一起附上，并说明想保留和修改的地方。

**前提：**Codex 环境需要实际提供可控制的浏览器工具，并能打开你的 ChatGPT 网页。仓库和 Python 包不会新增浏览器、替你登录或增加图像额度。若环境缺少工具，代理应如实报告，并给出手动回退；不能假装网页已经操作过。

## Codex 会自己完成什么

1. **准备环境。** 读取仓库和技能，调用 `tools/bootstrap.py` 在仓库建立 `.venv`，按返回的 Python 路径执行内部工具。无需用户先敲一遍安装命令。
2. **确认角色身份。** 在指定的已登录网页上传参考图，固定外观、比例、配色与道具，建立同一角色的生成上下文。
3. **先跑通一条。** 生成待机动作、下载真实原图，解码确认格式和透明度；这一条有问题就先修，不把同一缺陷扩散到整套图。
4. **补齐动作。** 逐条生成其余状态，下载并检查数量、间隙、裁切和身份。仅在角色适合且右跑已经审查时，才显式镜像出左跑；非对称角色独立生成。
5. **拼图并审查动作。** 调用内部 CLI 检查和组装，自行查看接触表、真实 GIF 或按时序的动作帧，审查头部大小、脚底、步态、跳跃升降和循环。若需临时交互预览，由代理后台验收后关闭；发现问题返回对应源行修复。
6. **安装。** 你已授权安装时，代理在实际看完并认可当前构建后记录审查、核对哈希并安装。已有同名目录会保留。最后区分“文件已安装”和“应用里已选中显示”。

内部脚本只做确定性的裁切、注册、拼接和检查。角色图来自实际网页生成，不以占位角色或未执行的脚本代替。

## 你可能仍需处理的事

- **首次登录或人机验证。** 由你在网页完成，代理保留进度后继续；不索取密码、Cookie 或 API Key。
- **账号额度或服务阻塞。** 图像生成依赖账号权限、套餐和剩余额度。网页卡住、限速或重复生成缺陷时，代理保留已完成行并说明阻塞，不无限消耗重试。
- **环境缺少 Python、终端或浏览器控制。** 自动准备环境也需要这些基础能力。代理应说明实际缺什么；仓库不能为任意 Codex 环境增加浏览器。
- **桌面最后的选择动作。** 文件装好后，若当前工具无法操作宠物选择界面，需要你选择新角色。代理会说明已经验证到哪一步。

用户选了网页生成，就不会悄悄切到其他付费 API。自动化目标是让代理承担制作过程，不保证任意网页版本或账号都无人值守完成。

## 会得到什么

- `source/`：网页实际下载的原图和显式处理配置。
- `frames/`、`final/`：真实源帧、**1536×1872** 透明 PNG 雪碧图和质量记录。
- `preview/`：检查图、GIF 等验收材料；可选生成自包含 HTML，供代理或高级调试查看。
- 当前构建的视觉审查记录，以及安装后的 `pet.json` 和图片。

九状态为：待机、向右跑、向左跑、挥手、跳跃、挫败、等待、专注工作、检查成果，共 57 个有效输出格。**画在图里的棋盘不是透明背景**；删除所有白色也会损坏白色衣物、眼睛或道具。技能检查真正的 alpha 并审查图像，不把几何通过当成动作已经合格。

当前目标是 **Codex 桌面本地宠物 v1**，已按桌面版 `26.1013` 核验。官方功能介绍：[Pets](https://learn.chatgpt.com/docs/pets)。本项目不是 ChatGPT Work 云端 Pets 上传器。

## 可选：安装技能供以后复用

首次也可以让 Codex 自己执行以下步骤；不要求用户预装。手动安装需 Python 3.10+：

```bash
python -m pip install "git+https://github.com/Andonis75/codex-various-pet.git"
various-pet install-skill
```

若命令不在 PATH，第二条用 `python -m codex_various_pet install-skill`。之后在新对话附图并调用 `$various-pet`，不必每次重新读取仓库。技能包自带运行入口，代理仍需使用当前环境实际可用的浏览器工具。
